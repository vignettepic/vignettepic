# VignettePic

VignettePic is a minimal, fast image viewer for macOS. Open an image and use the arrow keys to move through the other images in the same folder.

## Contact and support

Email: **vignettepic@gmail.com**

Bug reports and feature requests: [GitHub Issues](https://github.com/vignettepic/vignettepic/issues)

When you report a problem, please include:

- your macOS version and the VignettePic version,
- what you did and what happened instead,
- the image format, if the problem only happens with a specific file.

## FAQ

**Why does VignettePic ask for permission to access a folder?**
macOS gives the app access only to the image you opened. So that you can move to the previous and next image in the same folder, VignettePic asks you once to allow read access to that folder. If you decline, only the image you opened is shown.

**Which image formats are supported?**
The formats that macOS itself can read, for example JPEG, PNG, HEIC, WebP and TIFF. PDF files are not supported.

**Does VignettePic collect any data?**
No. See the [Privacy Policy](privacy/).
