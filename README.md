# Evrim Erdil

**Independent developer building thoughtful apps for Apple platforms.**

I create focused tools and personal experiences for Mac, iPhone, and iPad. My work brings together native interfaces, careful attention to detail, and practical everyday use.

## How I build

- **Simplicity:** clear interfaces that keep the main task in focus.
- **Privacy:** thoughtful handling of personal data, with on-device processing where possible.
- **Native experiences:** apps designed around the devices people use.
- **Care and support:** useful documentation and a clear place to ask for help.
